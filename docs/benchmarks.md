# Benchmarks

Every number here is regenerated by `benchmarks/level0_physics.py` per the
ecosystem benchmark standard (warm-up, repeated samples, percentiles, one
row per backend, provenance in the artefact). The operation is one pass
over a synthetic parameter grid evaluating, per point, the toroidal
equilibrium, the m = 1 growth estimate, the wall-stabilisation condition and
the end-loss scaling; the time is reported per grid point and includes the
Python call overhead of both backends (the native backend is called per
point through its binding, so this measures the call-through cost of the
kernels, not a vectorised scan). Nothing here is a physics claim.

## Fixed-runner (CI) number

Not yet published: the hosted `rust` job runs a benchmark smoke that
proves both backends measure, but the canonical fixed-runner artefact
requires a dispatchable benchmark workflow, which is held under the
current Actions cost policy. Until it exists, the only published number
is the local, non-isolated one above.

## Regenerate

```bash
make rust
VIRTUAL_ENV=.venv PATH=.venv/bin:$PATH maturin develop --release -m rust/Cargo.toml
.venv/bin/python benchmarks/level0_physics.py --points 100000 --warmup 3 --repeats 20 --label local
```
